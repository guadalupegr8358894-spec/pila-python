# Simulador Gráfico de una Pila (Stack) en Python

Programa interactivo desarrollado en Python utilizando **Tkinter** para visualizar el funcionamiento de una estructura de datos de tipo **Pila (LIFO)**.

## Características
- Inserción de elementos (`PUSH`)
- Eliminación de elementos (`POP`)
- Consulta del elemento superior (`PEEK`)
- Interfaz gráfica intuitiva con contenedor y indicador visual de tope.

## Requisitos
- Python instalado en tu equipo (la librería Tkinter viene incluida por defecto).

## Ejecución
Ejecuta el archivo principal desde tu terminal:
```bash
python pila_visual.py
